
# UNIT CONDITION INSPECTION REPORT

### User Story
As a **Operations Manager**, 
I want to **create unit inspection report(s)** automatically or at least have fields in the report populated, 
so that **the value of time** is given back. Currently 12 reports = 6 hours of time needed to produce.

### Acceptance Criteria
- [ ] Criterion 1: create a template report file, where the process can insert pictures into the report and add comments.
- [ ] Criterion 2: A config file that will show where report temple lives, shows where inspections images live, further reports live
- [ ] Criterion 3: Constraint of time it takes to create such reports for all warehouse cargo, AND in-transit cargo
